# InvoiceFlow AI v0.1.0

## Highlights

- AI-assisted invoice extraction behind a server-side provider boundary.
- Deterministic financial and business validation.
- PostgreSQL-backed workflow state and audit events.
- Human-in-the-loop review with Accept Exception and Reject workflows.
- Idempotent review resolution.
- React review queue and detail interface.
- Authenticated best-effort n8n automation.
- Loopback-restricted local Compose host bindings for API, frontend, and n8n.
- Backend, frontend, browser, static-analysis, and dependency security gates.
- Locally validated GitHub Actions CI configuration.

## Known limitations

- External webhook delivery is best effort.
- There is no transactional outbox or durable webhook retry queue.
- The deployment topology is local-development focused.
- No production HTTPS or full production monitoring stack is included.
- Playwright currently targets Chromium only.
- AI extraction accuracy has not yet been established against a governed
  production-quality benchmark.
- Authentication and authorization remain outside this release scope.

## Future direction

The post-v0.1.0 roadmap is Data Engineering first, followed by analytics,
Data Science, MLOps, and predictive intelligence when suitable historical data
exists.

## Release status

This is a local release candidate. Publication requires hosted CI verification
for the release-preparation commit and creation of the v0.1.0 tag only after
those checks pass.
